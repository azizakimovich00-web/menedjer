# Telegram Business Bot (Python + SQLite)

## Запуск
1. Создайте `.env` на основе `.env.example` и укажите `BOT_TOKEN`.
2. Установите зависимости: `pip install -r requirements.txt`
3. Запуск: `python main.py`

## Что реализовано
- Роли и доступы (director, accountant, manager, employee)
- PIN-код директора (установка/проверка)
- Основные меню по ролям
- Бухгалтерия: продажи/расходы/баланс/долги/история/экспорт/очистка
- Менеджер: новая заявка, задачи, материалы, базовые списки
- Менеджер: клиенты, заказы (создание, фильтры), отчеты, экспорт и очистка по разделам
- Директор: сотрудники, контакты, мои дела
- Хранение file_id для фото в заявках и заказах
- Планировщик уведомлений (базовый)
